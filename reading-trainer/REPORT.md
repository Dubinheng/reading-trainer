## 1. 项目概述

新世纪 Reading Trainer 是一个面向学生、教师和管理员的英语阅读训练网页应用。当前版本以单页 HTML 为主体，提供账号与邀请码、班级关系、阅读材料、AI 出题、答题批改、生词本、错题本、成绩趋势、教师中心和管理后台等能力。

项目最初由 WorkBuddy 整理并交接，随后依据 Illustrator 源稿、PNG 参考图和用户多轮视觉反馈，对登录页面进行了重新实现与反复校准，并对账号注册、角色关系和后台数据流程做了浏览器验证。

需要特别说明：当前交付物的核心范围是 **Reading Trainer（阅读训练）**。在早期描述中出现过“听力、TPO、打卡”等名称，但这些并未作为独立业务模块出现在当前 HTML 中，因此本报告不把它们列为已交付功能。

## 3. 从接手到当前版本的实施过程

### 阶段一：资料接收与基线核对

1. 核对 WorkBuddy 主文件、原报告和历史测试截图。
2. 核对 Illustrator 源稿、登录底板、登录框、Logo 与参考 PNG。
3. 将可维护副本整理到当前项目目录，保留原目录用于回溯。
4. 明确当前应用实际依赖 `assets/`：它不再是完全自包含的单文件，移动或部署时必须连同素材目录一起保留。

### 阶段二：登录页重新设计

登录页以电脑端为主要目标，同时保留窄屏适配。主要重构包括：

- 使用原始蓝绿色底板，不再依赖失真的整卡截图。
- 使用 HTML 表单覆盖在设计底板上，保留输入、选择、注册和后台登录的真实交互。
- 登录按钮改为居中；“管理者后台”和“注册新账号”放在按钮下方。
- 背景白色遮罩降低到约 24%，让原背景更清晰。
- 登录卡最大宽度约 480px，依据视口高度和 `.689 / 1` 纵向比例自动缩放。
- Logo 使用裁切后的紧凑版本，修正透明画布造成的比例失真。
- 增加背景缓慢漂移、卡片进入、元素分段进入、底板呼吸和按钮扫光动画。
- 遵循 `prefers-reduced-motion`，系统要求减少动画时停止持续动画。

### 阶段三：像素级视觉校准

根据用户截图和《名师简介-06》逐项修正：

1. **白卡水平居中**：底板自身透明边缘和视觉重量不对称，因此不能简单使用相同的 `left/right`。最终白卡使用 `left:10.85%`、`right:8.75%`，在 469×676 截图中左右可见边距均为 16px。
2. **恢复半透明旋转底片**：从原 PNG 读取到颜色为 `RGB(0,120,102)`、透明度约 44%，恢复为一整块旋转 3.3° 的图层，位于底板之上、白卡之下，右上和左下分别露出。
3. **缩短白卡上下高度**：最终使用 `top:5.4%`、`bottom:8.4%`。在 469×676 视口中，白卡与可见蓝绿色边框的顶部间距约 17px、底部约 18px。
4. **保持圆角完整**：白卡圆角、外框圆角和图层裁切均在卡片内部完成，没有直角溢出。

## 4. 当前功能清单

### 4.1 登录、注册与角色

- 学生和教师分别登录。
- 注册必须使用相应角色的邀请码。
- 同名学生与教师可按角色区分。
- 邀请码支持未使用、已使用和撤销状态。
- 登录会建立本地会话；退出后返回登录页。
- 首次打开时会自动初始化管理员账号。管理员凭据仅用于管理员登录，不在其他页面展示；正式部署前必须改为安全的后端配置。

### 4.2 管理者后台

后台包含六个页面：

1. 概览：教师数、学生数、可用邀请码数、AI 状态。
2. 邀请码：生成教师/学生邀请码，可绑定教师、复制和撤销。
3. AI 接口：选择服务商、接口地址、模型、API Key，保存并测试连接。
4. 账号管理：查看和删除学生、教师账号。
5. 班级管理：创建班级、设置班主任、查看学员、分配学生。
6. 飞书同步：保存 Access Token、查看 Base Token、启用并立即同步。

### 4.3 阅读练习

- 五级难度：小学五年级、初中、高中、大学四六级、雅思/托福。
- IELTS、TOEFL 或两者混合。
- 单篇或多篇文章，多篇使用单独一行 `====` 分隔。
- 题量范围 1–30。
- 八种题型：选择、判断、填空、词汇、段落匹配、标题匹配、流程图、句尾配对。
- 答题卡片模式与 A4/PDF 打印模式。
- 显示答案、逐题核对、提交批改、正确率统计、能力分析和学习建议。
- 智能自适应难度入口。
- AI 单题讲解入口。

### 4.4 学习资料与数据

- 内置文章库、个人收藏和教师分享文章。
- 生词提取、生词本和随机抽测。
- 错题自动入本、错题重做和五次掌握机制。
- 学生成绩记录、正确率曲线和题型统计。
- 教师查看名下学生的成绩、错题和生词。
- 教师文章库与学生可见的老师分享文章。

## 8. 已知问题与风险

### 高优先级

1. **纯前端账号不安全**：管理员、用户密码、AI Key 和飞书 Token 都以明文保存在浏览器或源代码中。
2. **默认管理员硬编码**：任何能查看源代码的人都能看到初始管理员凭据。
3. **无服务端权限控制**：前端角色限制可被浏览器开发者工具绕过，不适合存放真实学生数据。
4. **API Key 暴露**：客户端直接调用 AI 服务商会暴露 Key，并可能遭遇 CORS、额度盗用和接口滥用。
5. **飞书同步策略风险**：全量删除再重建缺少事务和恢复机制；同步内容还可能包含不应上传的敏感设置。

### 当前代码缺陷

1. HTML 中存在两个 `section[data-pane="teacher"]`。切换教师中心时两块会同时变为 active；其中一块是旧的 P3 占位内容，应删除或合并。
2. `itr-login-btn` 的点击事件被重复绑定两次，可能导致登录逻辑、提示和初始化重复执行。
3. 账号删除界面提示会一并删除学习数据，但当前实现主要删除账号记录，按用户 ID 保存的本地数据可能成为孤立数据。
4. WorkBuddy 旧报告中的 demo 账号与当前代码不一致。新浏览器中只会自动建立管理员，不会自动建立可登录的学生或教师账号。
5. 项目没有提交可重复运行的自动化测试套件；目前的 Playwright 截图和本报告中的浏览器复测属于验收证据，不是持续集成。
